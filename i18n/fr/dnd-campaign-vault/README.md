# Vault de campagne D&D — Modèle pour Obsidian

Un vault de gestion de campagne pour les jeux de rôle compatibles cinquième édition, bâti sur des tableaux de bord Dataview et une structure une-note-par-entité. Il est livré chargé avec **La Conspiration de la Route du Sel**, une mini-campagne originale complète — trois séances narrées, huit PNJ, quatre lieux liés, trois rencontres avec blocs de statistiques originaux, trois personnages joueurs et le contexte d'appui — de sorte que chaque requête, lien et flux de travail est démontré sur de vraies données de jeu. Ouvrez la vue graphique : un vault de campagne devrait ressembler à une toile, et c'est le cas de celui-ci.

Tout le contenu est original. Le vault est compatible en règles avec la 5e mais ne contient aucun texte d'un manuel publié.

## Structure

```
dnd-campaign-vault/
├── Commencez ici.md   ← à lire en premier
├── Écran du MJ.md     ← tableau de bord Dataview : PNJ par lieu, séances, rencontres, groupe
├── Séances/           ← 3 notes de séance (récap, indices, préparation)
├── PNJ/               ← 8 PNJ avec role / location / status / faction en frontmatter
├── Lieux/             ← 4 lieux liés entre eux
├── Rencontres/        ← 3 rencontres : 2 jouées, 1 préparée et prête
├── PJ/                ← 3 personnages joueurs avec liens et accroches
├── Contexte/          ← factions et histoire partagées entre les notes
└── Modèles/           ← séance, PNJ, lieu, rencontre, PJ
```

## Installation

1. Téléchargez et décompressez le modèle : **Décompresser → Obsidian → Ouvrir un dossier comme coffre**.
2. Quand Obsidian le demande, activez les plugins communautaires pour ce vault.
3. Installez Dataview, puis ouvrez `Écran du MJ.md` en mode lecture.

## Plugins

**Requis**

- Dataview — https://obsidian.md/plugins?id=dataview

**Optionnels**

- Leaflet — https://obsidian.md/plugins?id=obsidian-leaflet-plugin (cartes interactives dès que vous ajoutez des images de carte)
- Initiative Tracker — https://obsidian.md/plugins?id=initiative-tracker (ordre d'initiative dans la barre latérale)
