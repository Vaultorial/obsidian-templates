# Commencez ici

Bienvenue. Ce vault transforme Obsidian en système de prise de notes Cornell avec trois callouts et un snippet CSS — sans aucun plugin.

## Comment la disposition fonctionne

Chaque note Cornell est bâtie sur trois callouts :

- `> [!cue]` — la colonne étroite de gauche : questions et mots-clés, écrits *après* le cours.
- `> [!notes]` — la colonne large de droite : ce que vous capturez en direct.
- `> [!summary]` — le bandeau pleine largeur en bas : toute la page en deux ou trois phrases à vous.

Le snippet CSS inclus (`cornell`, déjà activé dans les réglages d'apparence de ce vault) fait flotter le callout d'indices à gauche, place celui des notes à côté et dégage le résumé en dessous — la page Cornell classique. Sur les fenêtres étroites, il se replie élégamment en blocs empilés. Si les colonnes apparaissent empilées sur une fenêtre large, vérifiez dans Paramètres → Apparence → Extraits de CSS que **cornell** est activé.

## Le flux de travail pour lequel la disposition est faite

1. **Pendant le cours :** n'écrire que dans la zone de notes. Lignes courtes, abréviations, les trous ne posent pas de problème.
2. **Le jour même, dix minutes :** remplir la colonne d'indices — transformer chaque bloc de notes en une question ou un mot-clé dans la marge.
3. **Ensuite le résumé :** deux ou trois phrases, avec vos mots, sans regarder la zone de notes.
4. **Pour réviser :** couvrir la colonne de notes et répondre aux questions des indices à voix haute. Les indices rendent l'auto-test possible ; le résumé dit à votre vous de demain de quoi parlait cette page.

## Premiers pas

1. Lisez une note d'exemple, puis son Markdown brut (basculez en vue d'édition) pour voir le peu de syntaxe en jeu.
2. Créez une note depuis `Modèles/Notes de cours (Cornell).md` — le plugin natif Templates est préconfiguré — et prenez-y vos prochaines notes.
3. Utilisez `Modèles/Note Cornell.md` pour le matériel hors cours : réunions, lectures, conférences.

## Plugins

Aucun requis, aucun suggéré. Seulement le plugin natif **Templates**, déjà pointé sur le dossier `Modèles`.
