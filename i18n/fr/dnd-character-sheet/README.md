# Vault feuille de personnage D&D — Modèle Obsidian

Une feuille de personnage D&D 5e sous forme de note Obsidian : caractéristiques, niveau et classe d'armure vivent dans les propriétés de la note, et Dataview calcule modificateurs, bonus de maîtrise, jets de sauvegarde, les dix-huit compétences, Perception passive et DD des sorts. Trois personnages d'exemple originaux et une feuille du groupe sont inclus. Les règles suivent le document de référence du système (SRD) de la 5e.

## Structure

```
dnd-character-sheet/  
├── Commencez ici.md    ← à lire en premier
├── Feuille du groupe.md  ← le groupe dans un tableau
├── Personnages/        ← 3 personnages remplis (guerrier, magicienne, roublarde)
└── Modèles/            ← Feuille de personnage vierge avec toutes les formules
```

## Installation

1. Téléchargez et décompressez le modèle : **Décompresser → Obsidian → Ouvrir le dossier comme vault**.
2. Quand Obsidian le demande, activez les plugins communautaires pour ce vault.
3. Installez Dataview, activez *JavaScript queries* dans ses réglages, puis ouvrez `Commencez ici.md`.

## Plugins

**Obligatoires**

- Dataview — https://obsidian.md/plugins?id=dataview
