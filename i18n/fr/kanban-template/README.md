# Tableau de projet Kanban — modèle Obsidian

Un flux de travail Kanban épuré pour Obsidian bâti sur le plugin Kanban : un tableau à quatre colonnes (À faire / En cours / Revue / Terminé) chargé d'un projet d'exemple réaliste — le lancement d'un blog personnel — plus le schéma carte-vers-note qui garde les tableaux lisibles pendant que la vraie réflexion vit dans des notes liées.

## Structure

```
kanban-template/
├── Commencez ici.md         ← lisez ceci en premier
├── Tableau de projet.md     ← le tableau Kanban (À faire / En cours / Revue / Terminé)
└── Cartes/                  ← cartes qui ont grandi en notes complètes
    ├── Choisir une plateforme de blog.md
    ├── Concevoir la mise en page de la page d'accueil.md
    ├── Rédiger l'annonce de lancement.md
    └── Configurer l'analytique et la search console.md
```

Comme les tableaux Kanban sont stockés en Markdown brut, le tableau reste lisible et comparable en diff même sans le plugin installé.

## Installation

1. Téléchargez et décompressez le modèle : **Décompresser → Obsidian → Ouvrir un dossier comme coffre**.
2. Quand Obsidian le demande, activez les plugins communautaires pour ce vault.
3. Installez le plugin Kanban et ouvrez `Tableau de projet.md`.

## Plugins

**Requis**

- Kanban — https://obsidian.md/plugins?id=obsidian-kanban

Aucun plugin optionnel. Le fichier du tableau est du Markdown brut en dessous.
