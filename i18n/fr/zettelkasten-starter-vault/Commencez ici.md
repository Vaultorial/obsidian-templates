# Commencez ici

Bienvenue. Ceci est un Zettelkasten petit mais *en état de marche* : quatorze vraies notes sur l'apprentissage et la mémoire, déjà liées, pour parcourir la méthode avant d'écrire une seule note à vous.

## Comment ce vault est organisé

- **Éphémères/** — des captures rapides dans votre propre sténographie. Bon marché, jetables, traitées sous un jour ou deux.
- **Littérature/** — des notes sur vos lectures, une note par source, rédigées dans vos propres mots avec la source nommée.
- **Permanentes/** — une idée par note, formulée comme une thèse, classée sous un identifiant horodaté comme `202605141030 Écrire ses notes avec ses propres mots`. Voilà le vrai Zettelkasten ; tout le reste n'est que préparation.
- **[[Index]]** — le point d'entrée. Les notes permanentes se retrouvent par les liens, et l'index retient les fils principaux.
- **Modèles/** — un modèle par type de note.

## Parcourez la chaîne une fois

Toute la méthode tient dans un seul pipeline. Suivez cet exemple résolu de bout en bout :

1. [[Pourquoi recopier des citations ne fixe pas les idées]] — une pensée éphémère, capturée en moins d'une minute.
2. [[How to Take Smart Notes - Ahrens]] — la note de littérature qui a donné un vocabulaire à la pensée.
3. [[202605141030 Écrire ses notes avec ses propres mots]] — la note permanente que les deux sont devenues : une idée, vos mots, liée vers l'avant.

Ouvrez ensuite l'[[Index]] et tirez le fil qui vous appelle.

## Premiers pas

1. Lisez les trois notes ci-dessus dans l'ordre.
2. Capturez aujourd'hui deux ou trois notes éphémères à vous — la vitesse avant le poli.
3. Demain, transformez la meilleure en note permanente avec `Modèles/Note permanente.md` : énoncez l'idée en une ou deux phrases, liez-la à au moins une note existante, ajoutez l'identifiant.
4. Supprimez la note éphémère une fois traitée. Cette suppression est le système qui fonctionne, pas une perte de données.

## Plugins

Fonctionne sans aucun plugin. Le plugin natif **Templates** est déjà configuré sur le dossier `Modèles`. En option, installez **Templater** (plugin communautaire, déjà autorisé dans la configuration de ce vault) pour que le modèle de note permanente appose lui-même son identifiant horodaté — sans lui, vous tapez simplement l'identifiant à la main.

> [!tip] La seule règle qui compte
> Une note permanente doit tenir debout toute seule : une idée, dite dans vos mots, liée à au moins une autre note. Tout le reste de la méthode est négociable.
