# Vault worldbuilding — Modèle pour Obsidian

Un système de worldbuilding pour romanciers, meneurs de jeu et bricoleurs de décors, bâti sur le frontmatter relationnel : chaque lieu, personnage, faction et événement déclare ses connexions, si bien que la vue graphique montre la vraie forme de votre monde et que Dataview assemble index et chronologies pour vous. Livré entièrement démontré avec **Les Cours des Marées** — un décor original de magie rare de deux douzaines de notes densément interconnectées : six lieux, sept personnages, trois factions, une culture, une croyance, un objet disputé et une chronologie de cinq événements qui court vers une crise.

## Structure

```
worldbuilding-vault/
├── Commencez ici.md   ← à lire en premier
├── Index du monde.md  ← MOC maître + synthèses Dataview
├── Chronologie.md     ← la frise, requêtée et racontée
├── Lieux/             ← 6 lieux (region, ruled-by)
├── Personnages/       ← 7 personnes (home, faction, role)
├── Factions/          ← 3 puissances (seat, leader)
├── Événements/        ← 5 événements (year, location, participants)
├── Cultures/          ← 1 culture (homeland, beliefs)
├── Croyances/         ← 1 croyance (followers, holy-place)
├── Objets/            ← 1 objet (held-by, location, origin)
├── Cartes/            ← vide ; la note à l'intérieur explique où vont les cartes
└── Modèles/           ← lieu, personnage, faction, événement, culture, croyance, objet
```

## Installation

1. Téléchargez et décompressez le modèle : **Décompresser → Obsidian → Ouvrir un dossier comme coffre**.
2. Quand Obsidian le demande, activez les plugins communautaires pour ce vault.
3. Installez Dataview, puis ouvrez `Index du monde.md` en mode lecture.

## Plugins

**Requis**

- Dataview — https://obsidian.md/plugins?id=dataview

**Optionnel**

- Timelines — https://obsidian.md/plugins?id=timelines-revamped (frises visuelles ; la chronologie requêtée fonctionne sans lui)
