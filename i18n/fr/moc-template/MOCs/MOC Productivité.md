# MOC Productivité

Des notes sur la gestion du temps et de l'attention. Agencées depuis *planifier la journée* vers l'extérieur, jusqu'à *protéger l'énergie qui rend les plans tenables*.

## Planification et structure

- [[Time blocking]] — donner un travail à chaque heure avant que la journée ne se mette à protester
- [[Revue hebdomadaire]] — le rituel d'entretien qui garde tous les autres systèmes honnêtes
- [[Traitement par lots]] — grouper les tâches superficielles pour qu'elles cessent de déchiqueter les heures profondes

## Vaincre la friction

- [[Règle des deux minutes]] — le plancher pour démarrer quand démarrer est le problème

## Le substrat

- [[Gestion de l'énergie]] — programmer le travail selon l'énergie, pas seulement selon le temps

## Fils vers d'autres cartes

- Une habitude d'écriture est un système de productivité appliqué à un métier : [[Habitude d'écriture quotidienne]] dans le [[MOC Écriture]]
- Bâtir une compétence côtoie la production : [[Pratique délibérée]] dans le [[MOC Apprentissage]]
