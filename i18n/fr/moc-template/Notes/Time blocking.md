# Time blocking

Up: [[MOC Productivité]]

Donner à chaque heure de travail une tâche à l'avance : l'agenda cesse d'être une liste de réunions et devient un plan pour l'attention. Le but n'est pas la rigidité — les blocs se déplacent sans cesse — c'est que *déplacer* un bloc est un arbitrage conscient, tandis qu'une heure non planifiée disparaît sans jamais avoir été décidée.

Deux règles le gardent honnête. Premièrement, bloquer le travail profond avant que quoi que ce soit d'autre ne réclame la place ; les tâches superficielles rempliront volontiers ce qui reste (à coupler avec le [[Traitement par lots]]). Deuxièmement, programmer contre l'énergie, pas seulement contre la disponibilité — un bloc profond à marée basse de la journée est une fiction (voir [[Gestion de l'énergie]]).

Lié : [[Revue hebdomadaire]] est l'endroit où se dessinent les blocs de la semaine suivante ; [[Habitude d'écriture quotidienne]] est un bloc défendu assez longtemps pour devenir une identité.
