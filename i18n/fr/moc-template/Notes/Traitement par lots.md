# Traitement par lots

Up: [[MOC Productivité]]

Grouper les tâches superficielles semblables — e-mails, courses, petites réparations, notes de frais — et les liquider en une seule séance dédiée plutôt que de les laisser perforer la journée. Chaque changement de contexte taxe l'attention deux fois : une fois pour quitter la tâche profonde, une fois pour rattraper le contexte de force. Le traitement par lots paie le coût du changement une seule fois pour toute la pile.

Forme pratique : un « bloc admin » quotidien ou biquotidien dans l'agenda, plus une liste de capture où les petites tâches attendent sans qu'on y pense. La liste compte autant que le bloc — une tâche groupée ne cesse de harceler qu'une fois écrite dans un endroit de confiance.

Lié : [[Time blocking]] donne aux lots un foyer pour qu'ils cessent de coloniser les heures profondes ; [[Règle des deux minutes]] décide de ce qui saute le lot entièrement.
