# Maison

Note de domaine pour l'endroit où je vis. Le test de ce qui appartient ici : négliger ça trois mois rendrait-il la vie nettement pire ? Alors c'est un domaine, pas une idée pour un jour.

## Le standard que je maintiens

- Remise à zéro de la cuisine chaque soir — cinq minutes, non négociable, améliore tous les matins.
- Check-list saisonnière deux fois par an : filtres, piles des détecteurs de fumée, joints de fenêtres, désencombrer un placard.
- Une liste de réparations au fil de l'eau dans cette note, plutôt que du harcèlement mental :
    - [ ] Refaire le joint silicone du lavabo
    - [ ] Remplacer la roulette bancale de la chaise de bureau
    - [x] Détartrer la bouilloire

## Focus actuel

La logistique des repas. L'essentiel du batch cooking qui attend dans la boîte ([[Extrait - l'essentiel du batch cooking]]) deviendra la note de référence là-dessus ; la cuisine du dimanche est la routine domestique au meilleur levier que j'aie essayée cette année.
