# Vault de démarrage PARA — second cerveau

Un vault de démarrage Obsidian qui met en œuvre la méthode PARA (Projets, Domaines — Areas —, Ressources, Archives). Il arrive pré-peuplé avec deux projets d'exemple actifs, trois domaines, des ressources liées, deux cartes de contenu et une boîte de réception qui illustre le flux capturer-puis-classer — la structure s'étudie, au lieu de seulement se lire.

## Structure des dossiers

```
para-starter-vault/
├── Commencez ici.md          ← à lire en premier
├── 00 Boîte de réception/    ← point de capture ; éléments en attente de classement
├── 01 Projets/               ← un sous-dossier par projet (note + notes enfants)
│   ├── Voyage au Japon juin 2026/
│   └── Lancement du site personnel/
├── 02 Domaines/              ← responsabilités continues (santé, carrière, maison)
├── 03 Ressources/            ← notes de référence et cartes de contenu
├── 04 Archives/              ← terminé/en pause (un exemple complet)
└── Modèles/                  ← modèles de projet, domaine et ressource
```

## Installation

1. Décompressez le téléchargement.
2. Ouvrez Obsidian → **Ouvrir le dossier comme vault** → sélectionnez le dossier décompressé.
3. Si Obsidian propose le mode restreint, vous pouvez le laisser activé — ce vault n'utilise aucun plugin communautaire.
4. Vérifiez que le plugin natif **Templates** est activé (Réglages → Plugins de base). Il est déjà configuré sur le dossier `Modèles`.

## Plugins

- **Requis :** aucun. Seulement le plugin natif Templates.
- **Facultatifs :** aucun.
