# Lancement de la refonte du site web

## Ordre du jour

1. Pourquoi maintenant : ce que le site actuel nous coûte
2. Périmètre et non-objectifs
3. Rôles, cadence, outils
4. Plan de découverte pour avril

## Notes

- Sarah a exposé le cas : le site met encore en avant la gamme de produits retirée, l'équipe de contenu ne peut pas éditer les pages de services sans Tom, et les plaintes sur la performance mobile reviennent dans les appels commerciaux.
- Périmètre convenu : message, modèles, accessibilité, redirections. Non-objectifs explicites : pas de refonte de marque, pas de changement de plateforme du blog, pas de nouveau CMS — on reconstruit les modèles sur l'actuel.
- Cadence : synchro hebdomadaire de 30 minutes le jeudi, revues de design à chaque jalon de design, décisions consignées dans ces notes plutôt que dans le chat.
- Découverte : Priya mène les entretiens avec les parties prenantes (ventes, support, les deux dernières recrues comme regard neuf) ; Tom extrait les données d'analytique et de crawl pour l'audit de contenu.

## Décisions

- Reconstruire sur le CMS existant ; ne reconsidérer que si le travail sur les modèles révèle un bloqueur.
- Sarah est la seule approbatrice du texte ; Helen pour tout ce qui touche aux pages de recrutement.
- Cible de lancement fixée au 2026-06-26, avant la campagne d'été.
