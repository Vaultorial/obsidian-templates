# Notes de lecture + suivi de lecture

Un modèle Obsidian pour tenir une note structurée par livre et suivre vos lectures avec une bibliothèque qui se met à jour toute seule. Le frontmatter contient les données (auteur, genre, note, statut, dates) ; Dataview les transforme en étagères — en cours de lecture, lus par note, à lire. Livré avec six vraies notes de livre dans des états variés pour que chaque requête ait une sortie visible.

## Structure des dossiers

```
book-notes-template/
├── Commencez ici.md  ← lisez ceci en premier
├── Bibliothèque.md   ← étagères Dataview : en cours / lus / à lire
├── Livres/           ← une note par livre (6 exemples inclus)
└── Modèles/          ← modèle de Note de livre
```

## Installation

1. Décompressez le téléchargement.
2. Ouvrez Obsidian → **Ouvrir un dossier comme coffre** → sélectionnez le dossier décompressé.
3. Désactivez le mode restreint quand on vous le demande, puis installez le plugin Dataview (lien ci-dessous) et activez-le.
4. Ouvrez `Bibliothèque.md` — les étagères devraient s'afficher avec les six livres inclus.

## Plugins

- **Requis :** Dataview — https://obsidian.md/plugins?id=dataview — alimente les requêtes de la Bibliothèque.
- **Optionnel :** Book Search — https://obsidian.md/plugins?id=obsidian-book-search-plugin — crée une note de livre avec titre, auteur et métadonnées préremplis depuis une recherche en ligne.
