# Commencez ici

Bienvenue. Ce vault est un système de notes quotidiennes avec quatre sections fixes — Agenda, Tâches, Journal et Gratitude — que vous pouvez remplir en moins de deux minutes ou développer en véritable journal. Rien d'autre à configurer.

## Comment le vault est organisé

- `Quotidien/` — une note par jour, nommée `YYYY-MM-DD`. Une semaine d'exemple complète (du 1er au 7 juin 2026) s'y trouve déjà, pour voir comment les sections se comportent avec de la vraie vie dedans.
- `Modèles/` — deux versions du même modèle quotidien :
	- **Note quotidienne (Templates natif)** — fonctionne telle quelle, sans plugin.
	- **Note quotidienne (Templater)** — même mise en page, plus des liens automatiques vers hier et demain. Nécessite le plugin Templater.

Le plugin natif **Daily notes** est déjà configuré : les nouvelles notes quotidiennes atterrissent dans `Quotidien/`, nommées par date, pré-remplies depuis le modèle natif.

## Premiers pas

1. Cliquez sur l'**icône calendrier** dans la barre latérale gauche (ou lancez `Ouvrir la note quotidienne du jour` depuis la palette de commandes). La note du jour se crée toute seule.
2. Avant de clore la journée, écrivez la tâche prioritaire de demain dans **Tâches** et une ligne dans **Journal**. Cette habitude à elle seule justifie le vault.
3. Parcourez la semaine d'exemple dans `Quotidien/`, puis supprimez-la quand vous n'avez plus besoin de la référence.
4. Ouvrez deux notes d'exemple côte à côte pour voir comment les liens `← préc. | suiv. →` relient les jours.

## Plugins

Par défaut, ce vault n'utilise que des plugins natifs (déjà activés). Amélioration facultative :

- **Templater** — installez-le et activez-le, définissez `Modèles` comme son dossier de modèles dans les réglages du plugin, puis pointez Daily notes (Paramètres → Notes quotidiennes → Modèle) vers `Note quotidienne (Templater)`. Dès lors, chaque nouvelle note quotidienne reçoit automatiquement la navigation précédent/suivant.

> [!tip] Gardez les sections, changez les questions
> Les quatre titres sont volontairement banals pour survivre aux journées chargées. Si la gratitude n'est pas votre truc, renommez la section « Une bonne chose » dans le modèle — mais gardez une section de clôture. Les notes quotidiennes meurent quand elles ne sont plus qu'une liste de tâches.
