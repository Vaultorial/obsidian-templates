# Buchnotizen + Lese-Tracker

Eine Obsidian-Vorlage, um eine strukturierte Notiz pro Buch zu führen und deine Lektüre mit einem sich selbst aktualisierenden Bücherregal zu verfolgen. Das Frontmatter hält die Daten (Autor, Genre, Bewertung, Status, Daten); Dataview verwandelt sie in Regale — lese ich gerade, gelesen nach Bewertung, Leseliste. Kommt mit sechs echten Buchnotizen in gemischten Zuständen, damit jede Abfrage sichtbare Ausgabe hat.

## Ordnerstruktur

```
book-notes-template/
├── Hier starten.md   ← lies das zuerst
├── Bücherregal.md    ← Dataview-Regale: lese ich / gelesen / Leseliste
├── Bücher/           ← eine Notiz pro Buch (6 Beispiele enthalten)
└── Vorlagen/         ← Buchnotiz-Vorlage
```

## Installation

1. Entpacke den Download.
2. Öffne Obsidian → **Ordner als Vault öffnen** → wähle den entpackten Ordner.
3. Schalte bei Aufforderung den eingeschränkten Modus aus, installiere dann das Dataview-Plugin (Link unten) und aktiviere es.
4. Öffne `Bücherregal.md` — die Regale sollten mit den sechs enthaltenen Büchern rendern.

## Plugins

- **Erforderlich:** Dataview — https://obsidian.md/plugins?id=dataview — treibt die Bücherregal-Abfragen an.
- **Optional:** Book Search — https://obsidian.md/plugins?id=obsidian-book-search-plugin — erstellt eine Buchnotiz mit Titel, Autor und Metadaten, vorgefüllt aus einer Online-Suche.
