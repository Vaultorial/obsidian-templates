# PARA-Starter-Vault — Second Brain

Ein Obsidian-Starter-Vault, der die PARA-Methode umsetzt (Projekte, Bereiche, Ressourcen, Archiv). Er kommt vorbefüllt mit zwei laufenden Beispielprojekten, drei Bereichen, verlinkten Ressourcen, zwei Maps of Content und einer Inbox, die den Erfassen-und-Ablegen-Workflow vorführt — die Struktur lässt sich also studieren, nicht nur nachlesen.

## Ordnerstruktur

```
para-starter-vault/
├── Hier starten.md           ← zuerst lesen
├── 00 Inbox/                 ← Sammelstelle; Einträge, die auf Ablage warten
├── 01 Projekte/              ← ein Unterordner pro Projekt (Notiz + Unternotizen)
│   ├── Japanreise Juni 2026/
│   └── Launch der eigenen Website/
├── 02 Bereiche/              ← laufende Verantwortlichkeiten (Gesundheit, Karriere, Zuhause)
├── 03 Ressourcen/            ← Referenznotizen und Maps of Content
├── 04 Archiv/                ← Abgeschlossenes/Pausiertes (ein durchgespieltes Beispiel)
└── Vorlagen/                 ← Projekt-, Bereichs- und Ressourcenvorlage
```

## Installation

1. Den Download entpacken.
2. Obsidian öffnen → **Ordner als Vault öffnen** → den entpackten Ordner auswählen.
3. Fragt Obsidian nach dem eingeschränkten Modus, kann er aktiviert bleiben — dieser Vault nutzt keine Community-Plugins.
4. Sicherstellen, dass das Core-Plugin **Templates** aktiviert ist (Einstellungen → Core-Plugins). Es ist bereits auf den Ordner `Vorlagen` eingestellt.

## Plugins

- **Erforderlich:** keine. Nur das Core-Plugin Templates.
- **Optional:** keine.
