# Warum abgeschriebene Zitate nie hängen bleiben

Schon wieder dabei ertappt, eine ganze Seite zu markieren. Ich kann eine Passage abschreiben und fühlen, dass sie mir gehört — eine Woche später kann ich sie nicht einmal umschreiben. Das Abschreiben *fühlt sich* nach Arbeit an, ist aber offenbar nicht der Teil, der zählt.

Knüpft an das an, was Ahrens über Schreiben als Denken sagt — siehe [[Das Zettelkasten-Prinzip - Ahrens]].
