# Die Idee als These formulieren

Eine Idee pro Notiz. Höchstens zwei Absätze, in eigenen Worten: zuerst die These selbst, dann warum sie trägt oder was aus ihr folgt. Schleicht sich eine zweite Idee ein, will sie eine eigene Notiz.

**Verwandt**

Mindestens eine bestehende permanente Notiz verlinken, mit einem Satz dazu, *wie* sie sich verhält — stützt, widerspricht, verallgemeinert, ist ein Fall von. In diesem Satz passiert das Denken.

**Quelle:** die Literaturnotiz verlinken, aus der das stammt, falls vorhanden.

> [!note] Benennung und ID
> Die Datei in `ID Titel` umbenennen (zum Beispiel `202605141030 Notizen in eigenen Worten schreiben`). Mit installiertem Templater füllt sich die `id` oben selbst; ohne es den Zeitstempel als YYYYMMDDHHMM tippen. Diesen Callout löschen, sobald die Notiz steht.
