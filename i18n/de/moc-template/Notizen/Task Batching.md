# Task Batching

Up: [[Produktivitäts-MOC]]

Ähnliche seichte Aufgaben bündeln — E-Mail, Besorgungen, kleine Reparaturen, Spesenformulare — und sie in einer eigenen Sitzung abräumen, statt sie den Tag perforieren zu lassen. Jeder Kontextwechsel besteuert die Aufmerksamkeit doppelt: einmal, um die tiefe Aufgabe zu verlassen, einmal, um den Kontext zurückzukrallen. Bündeln zahlt die Wechselkosten ein einziges Mal für den ganzen Stapel.

Praktische Form: ein täglicher oder zweimal täglicher "Admin-Block" im Kalender, plus eine Sammelliste, auf der kleine Aufgaben warten, ohne dass man an sie denkt. Die Liste zählt so viel wie der Block — eine gebündelte Aufgabe hört erst auf zu nerven, wenn sie an einem vertrauten Ort steht.

Verwandt: [[Time Blocking]] gibt den Bündeln ein Zuhause, damit sie die tiefen Stunden nicht besiedeln; [[Zwei-Minuten-Regel]] entscheidet, was das Bündel ganz überspringt.
