# Schreib-MOC

Notizen über das Erzeugen und Verbessern von Prosa. Die Anordnung spiegelt die Arbeit selbst: erzeugen, formen, polieren — und unter allem: weiter auftauchen.

## Erzeugen

- [[Freewriting]] — den inneren Lektor überholen, indem man sich weigert aufzuhören
- [[Outline vor dem Schreiben]] — das Argument festlegen, bevor man es schmückt

## Formen und polieren

- [[Überarbeiten in Durchgängen]] — ein Anliegen pro Durchgang; nie einen Entwurf redigieren, der noch strukturelle Probleme hat
- [[Für einen einzigen Leser schreiben]] — die Prosa auf eine einzelne reale Person zielen und zusehen, wie sie schärfer wird

## Die Praxis

- [[Tägliche Schreibroutine]] — klein, eingeplant, unheroisch — und gerade deshalb durchhaltbar
