# D&D-Charakterbogen-Vault — Obsidian-Vorlage

Ein D&D-5e-Charakterbogen als Obsidian-Notiz: Attribute, Stufe und Rüstungsklasse stehen in den Eigenschaften der Notiz, und Dataview berechnet Modifikatoren, Übungsbonus, Rettungswürfe, alle achtzehn Fertigkeiten, passive Wahrnehmung und Zauberrettungswurf-SG. Mit drei originalen Beispielfiguren und einem Gruppenbogen. Die Regeln folgen dem System Reference Document (SRD) für 5e.

## Struktur

```
dnd-character-sheet/  
├── Hier starten.md     ← zuerst lesen
├── Gruppenbogen.md     ← die Gruppe in einer Tabelle
├── Charaktere/         ← 3 ausgefüllte Figuren (Kämpfer, Magierin, Schurkin)
└── Vorlagen/           ← leerer Charakterbogen mit allen Formeln
```

## Installation

1. Vorlage herunterladen und entpacken: **Entpacken → Obsidian → Ordner als Vault öffnen**.
2. Wenn Obsidian fragt, Community-Plugins für diesen Vault aktivieren.
3. Dataview installieren, in den Einstellungen *JavaScript queries* einschalten und `Hier starten.md` öffnen.

## Plugins

**Erforderlich**

- Dataview — https://obsidian.md/plugins?id=dataview
