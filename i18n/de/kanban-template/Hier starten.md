# Hier starten

Willkommen. Dieser Vault ist ein minimales, funktionierendes Kanban-Setup für Obsidian: ein Board, vier Spalten und ein realistisches Beispielprojekt — der Launch eines persönlichen Blogs — schon in vollem Gange. Der Sinn der Vorlage ist nicht das Beispielprojekt; es ist das Workflow-Muster, bei dem Board-Karten zu vollwertigen Notizen heranwachsen, sobald sie Platz brauchen.

## Was hier ist

- [[Projekt-Board]] — das Kanban-Board. Vier Spalten: **Backlog** (alles, was du tun könntest), **In Arbeit** (woran du tatsächlich arbeitest, halte es bei zwei oder drei Karten), **Review** (fertig, aber ungeprüft), **Erledigt**.
- `Karten/` — Notizen, die als Board-Karten begannen. Vier der Beispielkarten sind mit einer Notiz hier verknüpft.

## Plugins zum Aktivieren

1. **Kanban** (erforderlich) — Einstellungen → Externe Erweiterungen → Durchsuchen → "Kanban". Ohne es öffnet sich [[Projekt-Board]] als schlichte Markdown-Liste — deine Daten sind nie eingesperrt, was der halbe Grund ist, dieses Plugin zu mögen.

## Der Karte-zu-Notiz-Workflow

Eine Karte auf dem Board sollte ein Einzeiler bleiben. Sobald eine Karte Unteraufgaben, Recherche, Entwürfe oder Links braucht, befördere sie:

1. Öffne das Kontextmenü der Karte (Rechtsklick auf die Karte oder das Drei-Punkte-Menü daran).
2. Wähle **Neue Notiz aus Karte**. Das Plugin erstellt eine nach der Karte benannte Notiz und ersetzt den Kartentext durch einen Link darauf.
3. Die Karte wandert weiter über das Board als Statusmarker; das Denken lebt in der Notiz.

Vier Karten auf dem Beispiel-Board haben das schon durchlaufen — [[Eine Blogging-Plattform wählen]], [[Das Homepage-Layout entwerfen]], [[Die Launch-Ankündigung schreiben]] und [[Analytics und Search Console einrichten]]. Öffne sie, um das Muster zu sehen: eine kurze Kontextzeile, der Arbeitsinhalt und ein Link zurück zum [[Projekt-Board]].

Standardmäßig landen neue Notizen im Vault-Stammverzeichnis; dieser Vault hält sie in `Karten/`. Stell das in den Board-Einstellungen ein (Board-Menü → **Board-Einstellungen** → Notizordner) oder zieh die Notizen einfach nachträglich in `Karten/`.

## Erste Schritte

1. Aktiviere das Kanban-Plugin und öffne [[Projekt-Board]].
2. Zieh eine Karte von Backlog nach In Arbeit. Hake eine in Review ab nach Erledigt.
3. Füge eine eigene Karte hinzu (klick auf **Karte hinzufügen** am Ende einer Spalte).
4. Befördere eine Karte zu einer Notiz, um ein Gefühl für den Workflow zu bekommen.
5. Wenn das Beispiel seinen Zweck erfüllt hat, bearbeite das Board direkt oder archiviere die Karten und beginne deine eigenen Spalten von Grund auf.
