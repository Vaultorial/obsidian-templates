# Kanban-Projekt-Board — Obsidian-Vorlage

Ein sauberer Kanban-Workflow für Obsidian auf Basis des Kanban-Plugins: ein vierspaltiges Board (Backlog / In Arbeit / Review / Erledigt), geladen mit einem realistischen Beispielprojekt — dem Launch eines persönlichen Blogs — plus dem Karte-zu-Notiz-Muster, das Boards überschaubar hält, während das eigentliche Denken in verknüpften Notizen lebt.

## Struktur

```
kanban-template/
├── Hier starten.md          ← lies das zuerst
├── Projekt-Board.md         ← das Kanban-Board (Backlog / In Arbeit / Review / Erledigt)
└── Karten/                  ← Karten, die zu vollwertigen Notizen herangewachsen sind
    ├── Eine Blogging-Plattform wählen.md
    ├── Das Homepage-Layout entwerfen.md
    ├── Die Launch-Ankündigung schreiben.md
    └── Analytics und Search Console einrichten.md
```

Da Kanban-Boards als schlichtes Markdown gespeichert werden, bleibt das Board lesbar und diff-bar, auch ohne installiertes Plugin.

## Installation

1. Lade die Vorlage herunter und entpacke sie: **Entpacken → Obsidian → Ordner als Vault öffnen**.
2. Wenn Obsidian fragt, aktiviere die Community-Plugins für diesen Vault.
3. Installiere das Kanban-Plugin und öffne `Projekt-Board.md`.

## Plugins

**Erforderlich**

- Kanban — https://obsidian.md/plugins?id=obsidian-kanban

Keine optionalen Plugins. Die Board-Datei ist darunter schlichtes Markdown.
