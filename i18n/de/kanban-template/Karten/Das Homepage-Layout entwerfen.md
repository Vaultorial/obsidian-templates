# Das Homepage-Layout entwerfen

Vom [[Projekt-Board]] befördert, als sich herausstellte, dass "die Homepage entwerfen" ein Dutzend kleinerer Entscheidungen verbarg. Arbeitsnotiz — derzeit in **In Arbeit**.

## Ziel

Eine Homepage, die drei Fragen in fünf Sekunden beantwortet: wer schreibt das, worum geht es, wo fange ich mit dem Lesen an.

## Layout-Skizze

1. Kurzer Vorstellungsblock — zwei Sätze, kein Foto-Karussell.
2. Die letzten drei Beiträge als schlichte Liste: Titel, Datum, einzeilige Zusammenfassung.
3. Eine "Hier starten"-Reihe, die auf die drei Beiträge zeigt, die Neulinge zuerst lesen sollen.
4. Fußzeile: RSS, Newsletter-Anmeldung, Kontakt.

## Arbeits-Checkliste

- [x] Wireframe auf Papier, drei Varianten
- [x] Variante B wählen (Vorstellung + Letzte + Hier-starten-Reihe)
- [ ] Den Vorstellungsblock bauen
- [ ] Die Beitragsliste mobile-first stylen
- [ ] Mit den längsten und kürzesten Beitragstiteln testen, die ich habe

## Notizen

- Widersteh der Tag-Wolke. Niemand navigiert per Tag-Wolke.
- Die "Hier starten"-Reihe kann für den Launch fest verdrahtet sein; später dynamisch machen, wenn sie sich ihren Platz verdient.
