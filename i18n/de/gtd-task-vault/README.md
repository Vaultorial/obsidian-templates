# GTD-Aufgaben-Vault — Obsidian-Vorlage

Ein gebrauchsfertiges Getting-Things-Done-System für Obsidian, angetrieben vom Tasks-Plugin. Es setzt die komplette GTD-Schleife um — erfassen, klären, organisieren, reflektieren, handeln — mit einem Live-Dashboard, Kontext-Tags und drei vollständig ausgearbeiteten Beispielprojekten, damit du das System in Aktion siehst, bevor du ihm deine eigene Arbeit anvertraust.

## Struktur

```
gtd-task-vault/
├── Hier starten.md             ← lies das zuerst
├── Dashboard.md                ← Live-Aufgaben-Queries (fällig, überfällig, Kontexte, wartend)
├── 00 Inbox.md                 ← erfasse hier alles
├── 01 Nächste Schritte.md      ← eigenständige Aktionen mit Kontext-Tags
├── 02 Warten auf.md            ← delegierte und blockierte Einträge
├── 03 Irgendwann oder Vielleicht.md ← Ideen ohne Verpflichtung
├── Projekte/                   ← eine Notiz pro Projekt, Aufgaben leben hier
│   ├── Küchenrenovierung.md
│   ├── Portfolio-Website-Auffrischung.md
│   └── Camping am See.md
└── Vorlagen/
    └── Projekt.md              ← Vorlage für neue Projektnotizen
```

GTD-Kontexte sind verschachtelte Tags (`#kontext/zuhause`, `#kontext/computer`, `#kontext/besorgungen`), da Obsidian-Tags nicht mit `@` beginnen dürfen.

## Installation

1. Lade die Vorlage herunter und entpacke sie: **Entpacken → Obsidian → Ordner als Vault öffnen**.
2. Wenn Obsidian fragt, aktiviere die Community-Plugins für diesen Vault.
3. Installiere die unten gelisteten Plugins und öffne `Dashboard.md` in der Leseansicht.

## Plugins

**Erforderlich**

- Tasks — https://obsidian.md/plugins?id=obsidian-tasks-plugin

**Optional**

- Dataview — https://obsidian.md/plugins?id=dataview (Projektübersichtstabelle im Dashboard)
