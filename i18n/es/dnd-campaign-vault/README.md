# Vault de campaña de D&D — Plantilla para Obsidian

Un vault de gestión de campañas para juegos de mesa compatibles con quinta edición, construido sobre paneles de Dataview y una estructura de una-nota-por-entidad. Viene cargado con **La conspiración de la Ruta de la Sal**, una minicampaña original completa — tres sesiones narradas, ocho PNJ, cuatro lugares enlazados, tres encuentros con bloques de estadísticas originales, tres personajes jugadores y el trasfondo de apoyo — de modo que cada consulta, enlace y flujo de trabajo está demostrado con datos de partida reales. Abre la vista de grafo: un vault de campaña debería parecer una red, y este lo parece.

Todo el contenido es original. El vault es compatible en reglas con 5e pero no contiene texto de ningún manual publicado.

## Estructura

```
dnd-campaign-vault/
├── Empieza aquí.md    ← lee esto primero
├── Pantalla del DM.md ← panel Dataview: PNJ por lugar, sesiones, encuentros, grupo
├── Sesiones/          ← 3 notas de sesión (resumen, pistas, preparación de la próxima)
├── PNJ/               ← 8 PNJ con frontmatter de role / location / status / faction
├── Lugares/           ← 4 lugares enlazados
├── Encuentros/        ← 3 encuentros: 2 jugados, 1 preparado y listo
├── PJ/                ← 3 personajes jugadores con vínculos y ganchos
├── Trasfondo/         ← facciones e historia compartidas entre notas
└── Plantillas/        ← sesión, PNJ, lugar, encuentro, PJ
```

## Instalación

1. Descarga y descomprime la plantilla: **Descomprimir → Obsidian → Abrir carpeta como vault**.
2. Cuando Obsidian pregunte, activa los plugins de la comunidad para este vault.
3. Instala Dataview y abre `Pantalla del DM.md` en vista de lectura.

## Plugins

**Obligatorio**

- Dataview — https://obsidian.md/plugins?id=dataview

**Opcionales**

- Leaflet — https://obsidian.md/plugins?id=obsidian-leaflet-plugin (mapas interactivos en cuanto añadas imágenes de mapa)
- Initiative Tracker — https://obsidian.md/plugins?id=initiative-tracker (orden de turnos en la barra lateral)
