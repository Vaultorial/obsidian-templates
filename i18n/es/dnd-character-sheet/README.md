# Vault de hoja de personaje de D&D — Plantilla de Obsidian

Una hoja de personaje de D&D 5e como nota de Obsidian: características, nivel y clase de armadura viven en las propiedades de la nota, y Dataview calcula modificadores, bonificador por competencia, tiradas de salvación, las dieciocho habilidades, Percepción pasiva y CD de conjuros. Incluye tres personajes de ejemplo originales y una hoja del grupo. Las reglas siguen el documento de referencia del sistema (SRD) de 5e.

## Estructura

```
dnd-character-sheet/  
├── Empieza aquí.md     ← léelo primero
├── Hoja del grupo.md   ← el grupo en una tabla
├── Personajes/         ← 3 personajes rellenos (guerrero, maga, pícara)
└── Plantillas/         ← Hoja de personaje en blanco con todas las fórmulas
```

## Instalación

1. Descarga y descomprime la plantilla: **Descomprimir → Obsidian → Abrir carpeta como vault**.
2. Cuando Obsidian lo pregunte, activa los plugins de la comunidad para este vault.
3. Instala Dataview, activa *JavaScript queries* en sus ajustes y abre `Empieza aquí.md`.

## Plugins

**Obligatorios**

- Dataview — https://obsidian.md/plugins?id=dataview
