# Pell

- **Aspecto:** Le faltan dos dedos, huele a brea.
- **Quiere:** Una copa que no puede pagar.
- **Voz:** Tararea canciones de marineros entre palabra y palabra.
- **Secreto:** Rema para el gremio pero odia a Shaw.

Conviértelo en PNJ completo cuando el grupo vuelva a buscarlo.
