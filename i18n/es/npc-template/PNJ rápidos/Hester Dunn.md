# Hester Dunn

- **Aspecto:** Mantón grueso, cuenta con un ábaco colgado de un cordel.
- **Quiere:** El cambio exacto, siempre.
- **Voz:** Repite el precio dos veces, la segunda más despacio.
- **Secreto:** Lleva un segundo libro de cuentas para Shaw.

Conviértelo en PNJ completo cuando el grupo vuelva a buscarlo.
