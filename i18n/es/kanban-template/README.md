# Tablero de proyecto Kanban — plantilla de Obsidian

Un flujo de trabajo Kanban limpio para Obsidian construido sobre el plugin Kanban: un tablero de cuatro columnas (Pendiente / En curso / Revisión / Hecho) cargado con un proyecto de ejemplo realista — lanzar un blog personal — más el patrón de tarjeta a nota que mantiene los tableros legibles mientras el pensamiento real vive en notas enlazadas.

## Estructura

```
kanban-template/
├── Empieza aquí.md          ← lee esto primero
├── Tablero de proyecto.md   ← el tablero Kanban (Pendiente / En curso / Revisión / Hecho)
└── Tarjetas/                ← tarjetas que crecieron hasta ser notas completas
    ├── Elegir una plataforma de blogging.md
    ├── Diseñar la maquetación de la página de inicio.md
    ├── Escribir el anuncio de lanzamiento.md
    └── Configurar analítica y search console.md
```

Como los tableros Kanban se guardan en Markdown plano, el tablero sigue siendo legible y comparable en diffs incluso sin el plugin instalado.

## Instalación

1. Descarga y descomprime la plantilla: **Descomprimir → Obsidian → Abrir una carpeta como bóveda**.
2. Cuando Obsidian lo pregunte, activa los plugins de la comunidad para este vault.
3. Instala el plugin Kanban y abre `Tablero de proyecto.md`.

## Plugins

**Obligatorios**

- Kanban — https://obsidian.md/plugins?id=obsidian-kanban

Sin plugins opcionales. El fichero del tablero es Markdown plano por debajo.
