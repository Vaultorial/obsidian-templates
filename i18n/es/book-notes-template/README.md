# Notas de libros + registro de lectura

Una plantilla de Obsidian para llevar una nota estructurada por libro y seguir tu lectura con una estantería que se actualiza sola. El frontmatter guarda los datos (autor, género, valoración, estado, fechas); Dataview los convierte en estantes — leyendo ahora, leídos por valoración, por leer. Viene con seis notas de libro reales en estados mixtos para que cada query tenga salida visible.

## Estructura de carpetas

```
book-notes-template/
├── Empieza aquí.md   ← lee esto primero
├── Estantería.md     ← estantes Dataview: leyendo / leídos / por leer
├── Libros/           ← una nota por libro (6 ejemplos incluidos)
└── Plantillas/       ← plantilla de Nota de libro
```

## Instalación

1. Descomprime la descarga.
2. Abre Obsidian → **Abrir carpeta como vault** → selecciona la carpeta descomprimida.
3. Desactiva el modo restringido cuando se te pregunte, luego instala el plugin Dataview (enlace abajo) y actívalo.
4. Abre `Estantería.md` — los estantes deberían renderizarse con los seis libros incluidos.

## Plugins

- **Obligatorios:** Dataview — https://obsidian.md/plugins?id=dataview — da vida a las queries de la Estantería.
- **Opcionales:** Book Search — https://obsidian.md/plugins?id=obsidian-book-search-plugin — crea una nota de libro con título, autor y metadatos rellenados desde una búsqueda en línea.
