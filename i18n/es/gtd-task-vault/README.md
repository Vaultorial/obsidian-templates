# Vault de tareas GTD — plantilla de Obsidian

Un sistema Getting Things Done listo para usar en Obsidian, impulsado por el plugin Tasks. Implementa el ciclo GTD completo — capturar, clarificar, organizar, reflexionar, actuar — con un panel en vivo, etiquetas de contexto y tres proyectos de ejemplo completamente desarrollados para que veas el sistema en marcha antes de confiarle tu propio trabajo.

## Estructura

```
gtd-task-vault/
├── Empieza aquí.md         ← lee esto primero
├── Panel.md                ← queries de tareas en vivo (vencen, vencidas, contextos, en espera)
├── 00 Bandeja de entrada.md← captura todo aquí
├── 01 Próximas acciones.md ← acciones sueltas con etiquetas de contexto
├── 02 En espera.md         ← elementos delegados y bloqueados
├── 03 Algún día o Quizá.md ← ideas sin compromiso
├── Proyectos/              ← una nota por proyecto, las tareas viven aquí
│   ├── Reforma de la cocina.md
│   ├── Renovación de la web de portfolio.md
│   └── Acampada junto al lago.md
└── Plantillas/
    └── Proyecto.md         ← plantilla para nuevas notas de proyecto
```

Los contextos de GTD son etiquetas anidadas (`#contexto/casa`, `#contexto/ordenador`, `#contexto/recados`), ya que las etiquetas de Obsidian no pueden empezar por `@`.

## Instalación

1. Descarga y descomprime la plantilla: **Descomprimir → Obsidian → Abrir carpeta como vault**.
2. Cuando Obsidian lo pregunte, activa los plugins de la comunidad para este vault.
3. Instala los plugins listados abajo y abre `Panel.md` en vista de lectura.

## Plugins

**Obligatorios**

- Tasks — https://obsidian.md/plugins?id=obsidian-tasks-plugin

**Opcionales**

- Dataview — https://obsidian.md/plugins?id=dataview (tabla resumen de proyectos en el panel)
