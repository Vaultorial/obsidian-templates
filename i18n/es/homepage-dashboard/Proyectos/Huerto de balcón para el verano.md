# Huerto de balcón para el verano

Convertir el balcón pelado orientado al sur en un pequeño huerto productivo antes del calor de julio: dos jardineras de tomates y albahaca, una de hojas de ensalada, y un riego que sobreviva a una semana fuera. Estado final a la vista: un cuenco de tomates propios para [[Salsa de tomate que funciona]].

## Tareas

- [x] Medir el balcón y comprobar la carga máxima de la barandilla [due:: 2026-05-24]
- [x] Comprar dos jardineras de 60 cm, sustrato y una paleta [due:: 2026-06-06]
- [ ] Trasplantar los plantones de tomate a las jardineras grandes [due:: 2026-06-10]
- [ ] Sembrar una segunda tanda de hojas de ensalada [due:: 2026-06-13]
- [ ] Instalar el riego por goteo y probarlo con una bandeja llena [due:: 2026-06-14]
- [ ] Escribir la nota de instrucciones de riego para la vecina [due:: 2026-06-19]

## Registro
