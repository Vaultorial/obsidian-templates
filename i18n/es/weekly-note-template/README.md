# Nota semanal + revisión semanal — Plantilla para Obsidian

Un sistema de planificación y revisión semanal para Obsidian en una sola nota por semana: plan del lunes, revisión de cierre estilo GTD (logros, números personales, pendientes que pasan de semana, foco de la siguiente). Incluye cuatro semanas de ejemplo consecutivas de mayo de 2026 para que veas cómo los frentes abiertos se mueven de una semana a otra.

## Estructura de carpetas

```
weekly-note-template/
├── Empieza aquí.md                       ← lee esto primero
├── Semanal/                              ← una nota por semana ISO (4 semanas de ejemplo)
│   ├── 2026-W19.md … 2026-W22.md
└── Plantillas/
    ├── Nota semanal (core Templates).md  ← sin plugins
    └── Nota semanal (Templater).md       ← añade rango de fechas + enlaces ant./sig.
```

## Instalación

1. Descomprime la descarga.
2. Abre Obsidian → **Abrir una carpeta como bóveda** → selecciona la carpeta descomprimida.
3. Confía en el vault cuando te lo pregunte (solo trae ajustes en JSON plano).
4. Abre `Empieza aquí.md`.

Si prefieres usarlo dentro de un vault existente, copia las carpetas `Semanal/` y `Plantillas/` y define `Plantillas` como tu carpeta de plantillas (Ajustes → Plantillas).

## Plugins

Obligatorios: ninguno — la variante core funciona desde el primer momento.

Opcionales:

- **Periodic Notes** — acceso con un comando a la nota de la semana en curso. https://obsidian.md/plugins?id=periodic-notes
- **Templater** — rangos de semana dinámicos y enlaces a la semana anterior/siguiente. https://obsidian.md/plugins?id=templater-obsidian
