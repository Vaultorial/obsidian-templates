# Vault de inicio PARA — segundo cerebro

Un vault de inicio para Obsidian que implementa el método PARA (Proyectos, Áreas, Recursos, Archivo). Viene prepoblado con dos proyectos de ejemplo en marcha, tres áreas, recursos enlazados, dos mapas de contenido y una bandeja de entrada que demuestra el flujo de capturar y archivar — para que la estructura sea algo que puedas estudiar, no solo leer.

## Estructura de carpetas

```
para-starter-vault/
├── Empieza aquí.md           ← lee esto primero
├── 00 Bandeja de entrada/    ← punto de captura; elementos pendientes de archivar
├── 01 Proyectos/             ← una subcarpeta por proyecto (nota + notas hijas)
│   ├── Viaje a Japón junio 2026/
│   └── Lanzamiento de la web personal/
├── 02 Áreas/                 ← responsabilidades continuas (salud, carrera, hogar)
├── 03 Recursos/              ← notas de referencia y mapas de contenido
├── 04 Archivo/               ← lo terminado o en pausa (un ejemplo resuelto)
└── Plantillas/               ← plantillas de proyecto, área y recurso
```

## Instalación

1. Descomprime la descarga.
2. Abre Obsidian → **Abrir una carpeta como bóveda** → selecciona la carpeta descomprimida.
3. Si Obsidian pregunta por el modo restringido, puedes dejarlo activado — este vault no usa plugins de la comunidad.
4. Comprueba que el plugin core **Templates** está activado (Ajustes → Complementos principales). Ya viene configurado para usar la carpeta `Plantillas`.

## Plugins

- **Obligatorios:** ninguno. Solo el Templates core.
- **Opcionales:** ninguno.
