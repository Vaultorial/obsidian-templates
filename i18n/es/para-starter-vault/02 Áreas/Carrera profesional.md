# Carrera profesional

Nota de área — el telón de fondo lento del que salen los proyectos. Los proyectos terminan; esto no.

## El estándar que mantengo

- Llevar un documento de logros vivo: una línea cada vez que algo sale bien o se publica, escrita el mismo día. Las futuras evaluaciones y el currículum se montan desde ahí, no desde la memoria.
- Una habilidad en desarrollo deliberado por trimestre. Este trimestre: escribir en público — de ahí salió [[Lanzamiento de la web personal]] como proyecto concreto.
- Un café o una llamada al mes con alguien de fuera de mi equipo directo. Los lazos débiles envejecen bien.

## Foco actual

El proyecto de la web es la parte visible. La parte silenciosa es decidir cuál será la habilidad del *próximo* trimestre antes de que acabe este, para que no haya hueco de deriva entre ambos.

## Cómo reviso esta área

Trimestral, de una sentada: releer el documento de logros, actualizar la página now (cuando [[Plan de contenidos de la web]] la publique), elegir la habilidad del siguiente trimestre y comprobar si alguna ambición de aquí merece ascender a carpeta de proyecto.
