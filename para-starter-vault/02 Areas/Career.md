# Career

Area note — the slow-moving backdrop that projects spin out of. Projects end; this does not.

## The standard I am maintaining

- Keep a running brag document: one line whenever something ships or lands well, written the same day. Future performance reviews and CVs get assembled from it, not from memory.
- One skill in deliberate development per quarter. This quarter: writing in public — which spun off [[Personal Website Launch]] as a concrete project.
- Coffee or a call with one person outside my immediate team each month. Loose ties age well.

## Current focus

The website project is the visible piece. The quiet piece is deciding what the *next* quarter's skill is before this one ends, so there is no drift gap between them.

## How I review this area

Quarterly, one sitting: reread the brag document, update the now page (once [[Website Content Plan]] ships it), pick the next quarter's skill, and check whether any ambition here deserves promotion to a real project folder.
