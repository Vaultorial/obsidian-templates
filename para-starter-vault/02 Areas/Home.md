# Home

Area note for the place I live. The test for what belongs here: would neglecting it for three months make life noticeably worse? Then it is an area, not a someday-idea.

## The standard I am maintaining

- Kitchen reset every night — five minutes, non-negotiable, makes every morning better.
- Seasonal checklist twice a year: filters, smoke alarm batteries, window seals, declutter one closet.
- A running fix-it list on this note instead of mental nagging:
    - [ ] Re-caulk the bathroom sink
    - [ ] Replace the wobbly desk chair wheel
    - [x] Descale the kettle

## Current focus

Food logistics. The batch cooking takeaways sitting in the inbox ([[Clipping - batch cooking takeaways]]) will become the reference note for this; the Sunday cook-up is the single highest-leverage home routine I have tried this year.
