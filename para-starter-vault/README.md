# Second Brain PARA Starter Vault

An Obsidian starter vault implementing the PARA method (Projects, Areas, Resources, Archive). It ships pre-populated with two live sample projects, three areas, linked resources, two maps of content and an inbox demonstrating the capture-and-file workflow — so the structure is something you can study, not just read about.

## Folder structure

```
para-starter-vault/
├── Start Here.md            ← read this first
├── 00 Inbox/                ← capture point; items waiting to be filed
├── 01 Projects/             ← one subfolder per project (note + child notes)
│   ├── Japan Trip June 2026/
│   └── Personal Website Launch/
├── 02 Areas/                ← ongoing responsibilities (Health, Career, Home)
├── 03 Resources/            ← reference notes and maps of content
├── 04 Archive/              ← completed/paused items (one worked example)
└── Templates/               ← project, area and resource templates
```

## Installation

1. Unzip the download.
2. Open Obsidian → **Open folder as vault** → select the unzipped folder.
3. If Obsidian asks about restricted mode, you can keep it on — this vault uses no community plugins.
4. Make sure the core **Templates** plugin is enabled (Settings → Core plugins). It is already configured to use the `Templates` folder.

## Plugins

- **Required:** none. Core Templates only.
- **Optional:** none.
