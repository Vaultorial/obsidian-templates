# Start Here

Welcome. This vault is a working PARA setup — not an empty shell. It already contains two live projects, three areas, a handful of resources, and an inbox with items waiting to be filed, so you can see how the method behaves before you commit to it.

## How PARA works here

Everything you capture lands in one of five folders, ordered by how actionable it is:

- **00 Inbox** — capture first, decide later. Nothing lives here permanently.
- **01 Projects** — outcomes with a deadline. Each project gets its own subfolder with a project note plus supporting notes.
- **02 Areas** — ongoing responsibilities with a standard to maintain, no end date. See [[Health Habits]], [[Career]] and [[Home]].
- **03 Resources** — topics you are interested in. Reference material, plus maps of content like [[Travel MOC]].
- **04 Archive** — finished or paused things. [[Spanish 30-Day Challenge]] shows what a completed project looks like after it moves here.

> [!tip] The folder test
> If you are unsure where a note goes, ask in order: Is it for a project I am committed to? An area I am responsible for? A topic I care about? If none — archive or delete.

## First steps

1. Open [[Japan Trip June 2026]] and [[Personal Website Launch]] to see how a project note ties its child notes together.
2. Read [[Clipping - batch cooking takeaways]] in the inbox — it walks through the filing decision in real time.
3. Create your own first project: duplicate the structure with the template in `Templates/Project.md` (insert it via the Templates command).
4. Once you are comfortable, replace the sample projects with your own and move these to `04 Archive` — or delete them outright.

## Plugins

No community plugins needed. Enable the **core Templates plugin** if it is not already on (Settings → Core plugins → Templates); it is pointed at the `Templates` folder. The three templates cover projects, areas and resources.
