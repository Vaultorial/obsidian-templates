# Habit Stacking

Reference note. Habit stacking means attaching a new habit to an existing one, using the formula *"after I [current habit], I will [new habit]"*. The existing habit acts as the trigger, so you never rely on remembering.

## Why it works (in practice, for me)

- The cue is something that already happens daily, so there is nothing new to remember.
- It forces the new habit to be small enough to fit in the seam between two existing actions.
- Failure is diagnostic: if the stack keeps breaking, the anchor habit was less solid than I thought.

## Stacks currently running

- After I start the coffee → empty the dishwasher (anchor for the [[Home]] kitchen reset).
- After I put on shoes in the morning → out the door for the walk ([[Health Habits]]).
- After I close the laptop on Friday → one line in the brag document ([[Career]]).
