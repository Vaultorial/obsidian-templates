# Book Notes + Reading Tracker

An Obsidian template for keeping one structured note per book and tracking your reading with a self-updating bookshelf. Frontmatter holds the data (author, genre, rating, status, dates); Dataview turns it into shelves — currently reading, read by rating, to-read. Ships with six real book notes in mixed states so every query has visible output.

## Folder structure

```
book-notes-template/
├── Start Here.md     ← read this first
├── Bookshelf.md      ← Dataview shelves: reading / read / to-read
├── Books/            ← one note per book (6 examples included)
└── Templates/        ← Book Note template
```

## Installation

1. Unzip the download.
2. Open Obsidian → **Open folder as vault** → select the unzipped folder.
3. Turn off restricted mode when prompted, then install the Dataview plugin (link below) and enable it.
4. Open `Bookshelf.md` — the shelves should render with the six included books.

## Plugins

- **Required:** Dataview — https://obsidian.md/plugins?id=dataview — powers the Bookshelf queries.
- **Optional:** Book Search — https://obsidian.md/plugins?id=obsidian-book-search-plugin — creates a book note with title, author and metadata pre-filled from an online search.
