# Weekly Note + Weekly Review — Obsidian Template

A weekly planning and review system for Obsidian in a single note per week: Monday plan, end-of-week GTD-style review (wins, personal numbers, carried-over items, next week's focus). Includes four consecutive example weeks from May 2026 so you can see how open loops move between weeks.

## Folder structure

```
weekly-note-template/
├── Start Here.md                       ← read this first
├── Weekly/                             ← one note per ISO week (4 example weeks)
│   ├── 2026-W19.md … 2026-W22.md
└── Templates/
    ├── Weekly Note (core Templates).md ← no plugins needed
    └── Weekly Note (Templater).md      ← adds date range + prev/next links
```

## Installation

1. Unzip the download.
2. Open Obsidian → **Open folder as vault** → select the unzipped folder.
3. Trust the vault when prompted (it ships with plain JSON settings only).
4. Open `Start Here.md`.

To use it inside an existing vault, copy `Weekly/` and `Templates/` in and set your template folder to `Templates` (Settings → Templates).

## Plugins

Required: none — the core variant works immediately.

Optional:

- **Periodic Notes** — one-command access to the current week's note. https://obsidian.md/plugins?id=periodic-notes
- **Templater** — dynamic week ranges and prev/next links. https://obsidian.md/plugins?id=templater-obsidian
