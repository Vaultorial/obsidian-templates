# Obsidian Templates by Vaultorial

Free, MIT-licensed Obsidian templates and starter vaults. Every folder in this
repo is a complete vault: unzip-free — clone it, open the folder as a vault in
Obsidian, and start from a working setup instead of a blank page.

Each template also has a page on [vaultorial.com](https://vaultorial.com/) with
a guided tour, the plugins it needs and a one-click zip download.

## How to use a template

1. Clone this repo (or download a zip from the template page).
2. In Obsidian, choose **Open folder as vault** and select the template folder.
3. Open `Start Here.md` inside the vault and follow the steps.

Each vault ships with a safe, minimal `.obsidian/` config (JSON only, no
binaries). If a template uses community plugins, its README lists them with
install links — nothing is bundled.
