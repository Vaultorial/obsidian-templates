# Daily Planner (Time Blocking) — Obsidian Template

A time-blocking daily planner for Obsidian: three Most Important Tasks, an hour-by-hour timeline in Day Planner syntax (`- [ ] 09:00 - 10:30 Deep work: report draft`), and an end-of-day shutdown ritual. Ships with three realistic example days and a weekly overview note.

## Folder structure

```
daily-planner-template/
├── Start Here.md                ← read this first
├── Planner/                     ← one note per day + week overview
│   ├── 2026-06-08.md … 2026-06-10.md
│   └── Week of 2026-06-08.md
└── Templates/
    ├── Daily Planner.md         ← auto-applied to new daily notes
    └── Weekly Overview.md
```

## Installation

1. Unzip the download.
2. Open Obsidian → **Open folder as vault** → select the unzipped folder.
3. Trust the vault when prompted (it ships with plain JSON settings only).
4. Open `Start Here.md`, then create today's note from the calendar ribbon icon.

To use it inside an existing vault, copy `Planner/` and `Templates/` in and point Daily notes at folder `Planner`, format `YYYY-MM-DD`, template `Templates/Daily Planner`.

## Plugins

Required: none — it works as plain checklists with core plugins.

Optional (recommended):

- **Day Planner** — renders the timeline blocks as a visual schedule with a live "now" indicator. https://obsidian.md/plugins?id=obsidian-day-planner
