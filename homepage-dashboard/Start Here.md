# Start Here

Welcome. This vault is a **homepage for your vault**: one note that greets you with today's tasks, your active projects, recent edits and quick links — instead of whatever file you had open last Tuesday. It comes in two strengths, both included and both already filled with a small working example vault (three projects, two areas, three evergreen notes).

## The two dashboards

- [[Home (simple)]] — callouts and static links, zero plugins. Open it now; it already works.
- [[Home]] — the live version. Dataview queries sweep every project and area for tasks tagged with `[due:: 2026-06-12]`-style dates and build the **Today** and **Coming up** sections for you. Needs the Dataview plugin.

The example notes around them are real enough to make the dashboard breathe: dated tasks, cross-links, an overdue item or two. Replace them with your own life at your own pace.

## How the vault is organized

- `Projects/` — work with an end state (a garden setup, a website refresh, a course).
- `Areas/` — ongoing responsibilities with no finish line (health, home upkeep).
- `Notes/` — evergreen reference: lists, checklists, recipes.

The convention that makes it all work: **every actionable task gets an inline due date**, like `- [ ] Rewrite the about page [due:: 2026-06-12]`. That single habit is what [[Home]] runs on.

## First steps

1. Open [[Home (simple)]] and click around the example vault to get the shape of it.
2. Install and enable **Dataview** (see README for links), then open [[Home]] — the queries come alive against the same notes.
3. Install **Homepage**, and in its settings choose `Home` as the page to open on startup (pick `Home (simple)` instead if you're staying plugin-free). That's the whole point of the vault: every session starts at the dashboard.
4. Make the dashboard yours: add a project note in `Projects/` with two or three dated tasks and watch it surface in **Coming up**.
5. When the example notes have served their purpose, delete them — the queries don't care, they read whatever is in the folders.

## Plugins

- **Dataview** — required for [[Home]], not for [[Home (simple)]].
- **Homepage** — opens your chosen dashboard on launch. Optional but it's the difference between having a homepage and having a note named Home.

> [!tip] Keep the homepage boring
> Resist adding every query you discover. A dashboard you glance at beats a dashboard you scroll. Today, this week, active projects, recent edits — if a section doesn't change a decision at 9:00, it goes.
