# About Maps

This folder ships empty (plus a `.gitkeep`) because the template contains no binary files. It is where your map images belong.

## How to use it

1. Drop image files here — exports from any map tool, scans of hand-drawn maps, whatever you have. Keep filenames lowercase and descriptive: `tide-courts-overview.png`, `lowmark-wards.png`, `causeway-crossings.png`.
2. Embed a map in any note with the standard embed syntax: `![[tide-courts-overview.png]]`.
3. Give each major map a companion note in this folder (for example a `Tide Courts Overview Map.md`) that embeds the image and lists what the map shows, linking each label to its place note — that way the map participates in the graph instead of being a dead end.

## Suggested set for this world

- One overview of the Shallow Sea and the bay, marking [[Ostreve]], [[Lowmark]], [[The Causeway of Bells]], [[The Mirrormoor]], [[Hethwick]] and [[The Drowned Abbey]].
- A tide-state pair: the same coastline at low water and at king tide. In the Tide Courts, two maps of one place is the entire point.
