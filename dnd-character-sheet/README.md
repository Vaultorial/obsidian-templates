# D&D Character Sheet Vault — Obsidian Template

A D&D 5e character sheet as an Obsidian note: ability scores, level and armor class live in the note's properties, and Dataview calculates modifiers, proficiency bonus, saving throws, all eighteen skills, Passive Perception and spell save DC. Three original example characters and a party sheet are included. Rules follow the 5e System Reference Document.

## Structure

```
dnd-character-sheet/  
├── Start Here.md       ← read this first
├── Party Sheet.md      ← the party in one table
├── Characters/         ← 3 filled characters (fighter, wizard, rogue)
└── Templates/          ← blank Character Sheet with every formula
```

## Installation

1. Download and unzip the template: **Unzip → Obsidian → Open folder as vault**.
2. When Obsidian asks, enable community plugins for this vault.
3. Install Dataview and switch on *JavaScript queries* in its settings, then open `Start Here.md`.

## Plugins

**Required**

- Dataview — https://obsidian.md/plugins?id=dataview
