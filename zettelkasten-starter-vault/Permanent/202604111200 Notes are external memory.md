# Notes are external memory

A note system is not a record of thinking that happened elsewhere — it is a place where part of the thinking happens. Working memory holds only a few items at once; a page holds as many as needed, indefinitely, without decay. Writing an idea down frees the head to operate *on* the idea instead of spending itself retaining it.

This reframes what a "good" note is. As storage, a note is good if it is faithful. As external memory, a note is good if my future self can resume the thought — which demands my own words, the reason it mattered, and links to where the thought connects. A perfect quotation fails this test; a rough paragraph in my own words passes it.
