# Interleaving helps tell concepts apart

Practicing related topics in mixed order (A-B-C-A-C-B) builds discrimination in a way that blocked practice (AAA-BBB-CCC) cannot. Blocked practice quietly removes the hardest part of the task: deciding *which kind of problem this is*. Once the block announces the answer, every repetition practices execution but never selection. Mixed practice keeps the identification step alive, which is exactly the step real situations demand.

Predictable cost: interleaved practice feels choppier and produces more errors during the session. That is the desirable-difficulty trade again — worse rehearsal, better performance later.
