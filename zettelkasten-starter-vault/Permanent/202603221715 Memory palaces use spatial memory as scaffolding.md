# Memory palaces use spatial memory as scaffolding

The method of loci works by translation: convert abstract items into vivid images, then place those images along a route you already know cold — your childhood home, your commute. To recall, you walk the route and collect what you planted. The technique borrows the strength of spatial memory, which holds places nearly effortlessly, and lends it to material that memory holds poorly, like sequences and abstractions.

Worth keeping the boundary of the tool honest: a memory palace stores *order and items*, not understanding. It answers "what comes next?", never "why?". For the why, the elaboration thread takes over.
