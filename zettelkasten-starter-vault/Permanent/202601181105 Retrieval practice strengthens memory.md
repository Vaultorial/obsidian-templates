# Retrieval practice strengthens memory

Pulling something *out* of memory strengthens it more than putting it back in. Reviewing notes is re-storage; closing the notes and reconstructing the idea is retrieval — and it is the retrieval attempt itself, even a failed one followed by checking, that does the strengthening. Rereading mostly trains recognition: the warm feeling of "I know this" that collapses the moment you must produce the idea unprompted.

Cheapest implementation I know: after reading anything, write what I remember *before* opening the source again. The permanent notes in this vault are retrieval practice wearing work clothes.
