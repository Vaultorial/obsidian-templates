# Spaced practice beats cramming

The same number of practice hours produces more durable memory when spread across days or weeks than when massed into one sitting. Cramming optimizes for the test of *right now*; spacing optimizes for still knowing it later. The catch is sensory: massed practice feels fluent and effective while it happens, spaced practice feels halting — so the worse strategy gets chosen precisely because of how it feels.

Practical consequence: schedule returns to material *after* it has begun to fade. The fading is part of the mechanism, not a failure of it — see [[202602031430 Difficulty during practice can be desirable]].
