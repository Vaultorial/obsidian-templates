# Start Here

Welcome. This is a small but *working* Zettelkasten: fourteen real notes about learning and memory, already linked, so you can walk the method before you write a single note of your own.

## How this vault is organized

- **Fleeting/** — quick captures in your own shorthand. Cheap, disposable, processed within a day or two.
- **Literature/** — notes on things you read, one note per source, written in your own words with the source named.
- **Permanent/** — one idea per note, written as a claim, filed with a timestamp ID like `202605141030 Write notes in your own words`. These are the actual Zettelkasten; everything else is staging.
- **[[Index]]** — the entry point. Permanent notes are findable through links, and the index holds the main threads.
- **Templates/** — one template per note type.

## Walk the chain once

The whole method is one pipeline. Follow this worked example end to end:

1. [[Why copying quotes never sticks]] — a fleeting thought, captured in under a minute.
2. [[How to Take Smart Notes - Ahrens]] — the literature note that gave the thought a vocabulary.
3. [[202605141030 Write notes in your own words]] — the permanent note the two became: one idea, own words, linked onward.

Then open [[Index]] and follow any thread that pulls.

## First steps

1. Read the three notes above in order.
2. Capture two or three fleeting notes of your own today — speed over polish.
3. Tomorrow, turn the best one into a permanent note using `Templates/Permanent Note.md`: state the idea in one or two sentences, link it to at least one existing note, add the ID.
4. Delete the fleeting note once processed. That deletion is the system working, not data loss.

## Plugins

Works with zero plugins. The core **Templates** plugin is preconfigured for the `Templates` folder. Optionally install **Templater** (community plugin, already whitelisted in this vault's config) so the permanent-note template stamps its own timestamp ID — without it, you just type the ID by hand.

> [!tip] The only rule that matters
> A permanent note must stand on its own: one idea, stated in your words, linked to at least one other note. Everything else in the method is negotiable.
