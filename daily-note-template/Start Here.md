# Start Here

Welcome. This vault is a daily note system with four fixed sections — Agenda, Tasks, Log, Gratitude — that you can fill in under two minutes or expand into a full journal. Nothing else to configure.

## How the vault is organized

- `Daily/` — one note per day, named `YYYY-MM-DD`. A full example week (June 1–7, 2026) is already in here so you can see how the sections behave with real life in them.
- `Templates/` — two versions of the same daily template:
	- **Daily Note (core Templates)** — works out of the box, no plugins.
	- **Daily Note (Templater)** — same layout plus automatic yesterday/tomorrow links. Needs the Templater plugin.

The core **Daily notes** plugin is already configured: new daily notes land in `Daily/`, named by date, pre-filled from the core template.

## First steps

1. Click the **calendar icon** in the left ribbon (or run `Open today's daily note` from the command palette). Today's note is created for you.
2. Write tomorrow's top task in **Tasks** and one line in **Log** before closing the day. That habit alone makes the vault worth keeping.
3. Skim the example week in `Daily/`, then delete it when you no longer need the reference.
4. Open any two example notes side by side to see how the `← prev | next →` links connect days.

## Plugins

Out of the box this vault only uses core plugins (already enabled). Optional upgrade:

- **Templater** — install and enable it, set `Templates` as its template folder in the plugin settings, then point Daily notes (Settings → Daily notes → Template) at `Daily Note (Templater)`. From then on every new daily note gets working prev/next navigation automatically.

> [!tip] Keep the sections, change the prompts
> The four headings are deliberately boring so they survive busy days. If Gratitude is not your thing, rename it to "One good thing" in the template — but keep a closing section. Daily notes die when they are only a task list.
