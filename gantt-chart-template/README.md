# Gantt Chart Vault — Obsidian Template

Gantt charts drawn from your notes: every task is a note with start and end dates in its properties, and a DataviewJS query turns them into a Mermaid Gantt chart per project, with a section per phase. Two example projects, a plugin-free static example and a task template are included.

## Structure

```
gantt-chart-template/
├── Start Here.md              ← read this first
├── Timeline.md                ← the generated charts
├── Static Gantt Example.md    ← hand-written chart, no plugin
├── Projects/                  ← 2 example projects, 14 dated tasks
└── Templates/                 ← blank Task note
```

## Installation

1. Download and unzip the template: **Unzip → Obsidian → Open folder as vault**.
2. When Obsidian asks, enable community plugins for this vault.
3. Install Dataview, switch on *JavaScript queries* in its settings, then open `Timeline.md`.

## Plugins

**Required**

- Dataview — https://obsidian.md/plugins?id=dataview
