# D&D Campaign Vault — Obsidian Template

A campaign management vault for fifth-edition-compatible tabletop games, built around Dataview dashboards and one-note-per-entity structure. It ships loaded with **The Salt Road Conspiracy**, a complete original mini-campaign — three narrated sessions, eight NPCs, four linked locations, three encounters with original stat blocks, three player characters and supporting lore — so every query, link and workflow is demonstrated with real play data. Open the graph view: a campaign vault should look like a web, and this one does.

All content is original. The vault is rules-compatible with 5e but contains no text from any published rulebook.

## Structure

```
dnd-campaign-vault/
├── Start Here.md     ← read this first
├── DM Screen.md      ← Dataview dashboard: NPCs by location, sessions, encounters, party
├── Sessions/         ← 3 session notes (recap, clues, next-time prep)
├── NPCs/             ← 8 NPCs with role / location / status / faction frontmatter
├── Locations/        ← 4 linked locations
├── Encounters/       ← 3 encounters: 2 run, 1 prepped and ready
├── PCs/              ← 3 player characters with bonds and hooks
├── Lore/             ← factions and history shared across notes
└── Templates/        ← Session, NPC, Location, Encounter, PC
```

## Installation

1. Download and unzip the template: **Unzip → Obsidian → Open folder as vault**.
2. When Obsidian asks, enable community plugins for this vault.
3. Install Dataview, then open `DM Screen.md` in reading view.

## Plugins

**Required**

- Dataview — https://obsidian.md/plugins?id=dataview

**Optional**

- Leaflet — https://obsidian.md/plugins?id=obsidian-leaflet-plugin (interactive maps once you add map images)
- Initiative Tracker — https://obsidian.md/plugins?id=initiative-tracker (turn order in the sidebar)
