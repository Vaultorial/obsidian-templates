# Journal / Bullet Journal — Obsidian Template

A bullet-journal style journaling vault for Obsidian: rapid logging with the classic notation (`•` task, `×` done, `○` event, `–` note, `>` migrated), a short gratitude section per entry, monthly folders, and a monthly reflection ritual. Ships with two full example weeks (May 25 – June 7, 2026) and a completed monthly reflection for May.

## Folder structure

```
journal-template/
├── Start Here.md                          ← read this first (includes the logging key)
├── Journal/
│   └── 2026/
│       ├── 05/                            ← 7 entries + "2026-05 Reflection.md"
│       └── 06/                            ← 7 entries
└── Templates/
    ├── Journal Entry (bullet journal).md  ← default for new daily notes
    ├── Journal Entry (daily journal).md   ← long-form prose variant
    ├── Journal Entry (Templater).md       ← adds prev/next day links
    └── Monthly Reflection.md
```

## Installation

1. Unzip the download.
2. Open Obsidian → **Open folder as vault** → select the unzipped folder.
3. Trust the vault when prompted (it ships with plain JSON settings only).
4. Open `Start Here.md`, then hit the calendar icon for today's entry.

To use it inside an existing vault, copy `Journal/` and `Templates/` in and set Daily notes to folder `Journal`, format `YYYY/MM/YYYY-MM-DD`, template `Templates/Journal Entry (bullet journal)`.

## Plugins

Required: none.

Optional:

- **Templater** — dynamic dates and prev/next entry links for the Templater variant. https://obsidian.md/plugins?id=templater-obsidian
