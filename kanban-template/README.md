# Kanban Project Board — Obsidian Template

A clean Kanban workflow for Obsidian built on the Kanban plugin: a four-column board (Backlog / Doing / Review / Done) loaded with a realistic example project — launching a personal blog — plus the card-to-note pattern that keeps boards skimmable while the real thinking lives in linked notes.

## Structure

```
kanban-template/
├── Start Here.md       ← read this first
├── Project Board.md    ← the Kanban board (Backlog / Doing / Review / Done)
└── Cards/              ← cards that grew into full notes
    ├── Choose a blogging platform.md
    ├── Design the homepage layout.md
    ├── Write the launch announcement.md
    └── Set up analytics and search console.md
```

Because Kanban boards are stored as plain Markdown, the board stays readable and diff-able even without the plugin installed.

## Installation

1. Download and unzip the template: **Unzip → Obsidian → Open folder as vault**.
2. When Obsidian asks, enable community plugins for this vault.
3. Install the Kanban plugin and open `Project Board.md`.

## Plugins

**Required**

- Kanban — https://obsidian.md/plugins?id=obsidian-kanban

No optional plugins. The board file is plain Markdown underneath.
