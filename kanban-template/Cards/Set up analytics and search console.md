# Set up analytics and search console

Escalated from [[Project Board]] while still in **Backlog** — a good example of the third reason to convert a card: parking research before the work starts.

## Scope

- Privacy-friendly analytics: page views and referrers are enough. No cookies, no consent banner if avoidable.
- Register the site with the major search engines' webmaster consoles and submit the sitemap.

## Research notes

- Shortlist two lightweight analytics options: one self-hosted, one hosted. Decide by maintenance cost, not features — this is a personal blog, not a funnel.
- The static site generator emits `sitemap.xml` already; confirm it is referenced from `robots.txt`.
- Set a calendar reminder to actually look at the analytics monthly. Data nobody reads is just liability.

## Done means

- [ ] Analytics script live on all pages
- [ ] Sitemap submitted and accepted
- [ ] One bookmark to the stats page, one monthly reminder
