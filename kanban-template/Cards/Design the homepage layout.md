# Design the homepage layout

Escalated from [[Project Board]] when "design the homepage" turned out to hide a dozen smaller decisions. Working note — currently in **Doing**.

## Goal

A homepage that answers three questions in five seconds: who writes this, what is it about, where do I start reading.

## Layout sketch

1. Short intro block — two sentences, no photo carousel.
2. Latest three posts as a simple list: title, date, one-line summary.
3. A "start here" row pointing to the three posts I want newcomers to read first.
4. Footer: RSS, newsletter signup, contact.

## Working checklist

- [x] Wireframe on paper, three variants
- [x] Pick variant B (intro + latest + start-here row)
- [ ] Build the intro block
- [ ] Style the post list for mobile first
- [ ] Test with the longest and shortest post titles I have

## Notes

- Resist the tag cloud. Nobody navigates by tag cloud.
- The "start here" row can be hard-coded for launch; make it dynamic later if it earns its keep.
