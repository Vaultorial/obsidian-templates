# Start Here

Welcome. This vault is a minimal, working Kanban setup for Obsidian: one board, four columns, and a realistic example project — launching a personal blog — already in flight. The point of the template is not the example project; it is the workflow pattern of board cards that grow into full notes when they need room.

## What is here

- [[Project Board]] — the Kanban board. Four columns: **Backlog** (everything you might do), **Doing** (what you are actually working on, keep it to two or three cards), **Review** (done but not checked), **Done**.
- `Cards/` — notes that started life as board cards. Four of the example cards are linked to a note here.

## Plugins to enable

1. **Kanban** (required) — Settings → Community plugins → Browse → "Kanban". Without it, [[Project Board]] opens as a plain Markdown list — your data is never locked in, which is half the reason to like this plugin.

## The card-to-note workflow

A card on the board should stay a one-liner. The moment a card needs sub-tasks, research, drafts, or links, escalate it:

1. Open the card's context menu (right-click the card, or the three-dot menu on it).
2. Choose **New note from card**. The plugin creates a note named after the card and replaces the card text with a link to it.
3. The card keeps moving across the board as a status marker; the thinking lives in the note.

Four cards on the example board already went through this — [[Choose a blogging platform]], [[Design the homepage layout]], [[Write the launch announcement]] and [[Set up analytics and search console]]. Open them to see the pattern: a short context line, the working content, and a link back to [[Project Board]].

By default new notes land in the vault root; this vault keeps them in `Cards/`. Set that in the board settings (board menu → **Board settings** → note folder) or just drag notes into `Cards/` afterwards.

## First steps

1. Enable the Kanban plugin and open [[Project Board]].
2. Drag a card from Backlog to Doing. Tick one in Review off to Done.
3. Add a card of your own (click **Add a card** at the bottom of a column).
4. Escalate one card into a note to get a feel for the workflow.
5. When the example has done its job, edit the board in place or archive the cards and start your own columns from scratch.
