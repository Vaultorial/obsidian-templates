# Daily Writing Habit

Up: [[Writing MOC]]

Small and scheduled beats big and inspired. A modest daily session — even twenty minutes — keeps the project warm, so each day starts inside the work instead of at the cold cost of re-entry. Waiting for free weekends produces heroic sessions weeks apart, and most of each one is spent remembering where things stood.

Design it like infrastructure, not a vow: same time daily, a fixed trigger, and a floor so low it survives bad days (one paragraph counts; opening the file counts twice). End each session mid-thought with a note about what comes next — tomorrow's start is then free.

Related: [[Time Blocking]] in the [[Productivity MOC]] gives the session a defended slot; [[Deliberate Practice]] in the [[Learning MOC]] is what the session becomes once showing up is no longer the hard part; [[Freewriting]] is the emergency starter for days when nothing moves.
