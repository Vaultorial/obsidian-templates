# Spaced Repetition

Up: [[Learning MOC]]

Review material on a widening schedule — tomorrow, then in a few days, then next week — returning to each idea around the time it starts to slip. Each effortful return strengthens the memory more than a comfortable same-day repeat, which is why cramming feels efficient and evaporates, while spaced practice feels halting and lasts.

It pairs with one non-negotiable partner: the review must be a recall attempt, not a reread. Spacing decides *when*; [[Active Recall]] decides *what happens* each time. Flashcard apps automate the scheduling, but a calendar reminder and a list of questions do the same job for small amounts of material.

Related: [[Deliberate Practice]] applies the same return-to-the-hard-part logic to skills; [[Daily Writing Habit]] in the [[Writing MOC]] shows spacing's cousin — small and regular beating big and rare.
