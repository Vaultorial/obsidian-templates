# Task Batching

Up: [[Productivity MOC]]

Group similar shallow tasks — email, errands, small fixes, expense forms — and clear them in one dedicated sitting instead of letting them perforate the day. Every context switch taxes attention twice: once to leave the deep task, once to claw the context back. Batching pays the switching cost a single time for the whole pile.

Practical shape: a daily or twice-daily "admin block" on the calendar, plus a capture list where small tasks wait without being thought about. The list matters as much as the block — a batched task only stops nagging once it is written somewhere trusted.

Related: [[Time Blocking]] gives batches a home so they stop colonizing deep hours; [[Two-Minute Rule]] decides what skips the batch entirely.
